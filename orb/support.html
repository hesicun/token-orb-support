Token Orb · Support / 使用帮助

Updated / 更新：2026-11-03 · JVH

English

Token Orb is a desktop quota and balance dashboard for macOS 14 or later. Configure one provider endpoint and one API Key.

In Settings, enter your provider display name and authorized HTTPS GET JSON quota endpoint. Choose Bearer, x-api-key or no authentication. Enter the Key only in the secure Key field, never in the URL. Verify that you trust the endpoint owner before saving.

Supported quota JSON can be detected automatically. For other schemas, disable automatic detection and map explicit dot paths, such as data.remaining. Allowance responses need a remaining amount plus total, or an explicit remaining percentage from 0 to 100. A balance response uses a configured display basis. Ordinary chat APIs do not necessarily expose balances; webpages, POST/signature authentication and arbitrary response formats are not supported by the custom adapter.

Queries run approximately every 60 seconds while preview is off. Redirects, cookies, URL credentials and query parameters are refused for custom APIs. Failures keep the last result with an error; check the update time before treating it as current. Balance displays do not invent reset times.

Use the app language setting and restart to apply it to all windows and menus. Delete the saved Key before uninstalling. Deleting locally does not revoke the Key at your provider.

Support: hesicun@msn.com. Send the app/macOS version and a redacted error description. Never email Keys, passwords or unredacted account information.

Click the orb to cycle detected quota windows, drag to move it, and right-click for Settings. A reset ring appears only when a complete period is known.

简体中文

Token Orb 是适用于 macOS 14 及以上的桌面额度和余额看板。一次配置一个自定义厂商地址和一个 API Key。

在设置中填写厂商显示名和你有权访问的 HTTPS GET JSON 额度地址，选择 Bearer、x-api-key 或无需认证。Key 只填入安全密钥框，不要放进 URL。保存前确认地址属于你信任的服务。

支持的额度 JSON 可自动识别；其他结构请关闭自动识别并设置点号路径，例如 data.remaining。套餐需要剩余量及总量，或明确的 0–100 剩余百分比；余额按你设置的基准显示。普通聊天 API 不一定提供余额，自定义适配器不支持网页、POST／签名认证或任意响应格式。

关闭预览后约每 60 秒查询一次。自定义接口拒绝重定向、Cookie、URL 内凭据及查询参数。失败会保留上次结果并显示错误，请结合更新时间判断是否过期。余额不会虚构重置周期。

可在应用设置中选择语言，重启后所有窗口和菜单生效。卸载前请删除已保存 Key；本机删除不等于在厂商处撤销密钥。

支持：hesicun@msn.com。请提供应用／macOS 版本及遮盖敏感信息后的错误说明，不要发送 Key、密码或未遮盖的账户信息。

点击球身切换已识别额度窗口，拖动移动，右键打开设置。只有完整周期信息可信时才显示重置圆环。
