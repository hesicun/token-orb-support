Token Orb · Overview / 产品说明

Updated / 更新：2026-11-03 · JVH

English

Token Orb is a desktop quota and balance dashboard for macOS 14 or later. Configure one provider endpoint and one API Key.

Preparing for global App Store release as a USD 1.99 one-time purchase, without subscriptions or in-app purchases. It is not yet available for purchase; local storefront prices may differ. Third-party credits and query fees are separate.

English and Simplified Chinese UI; other system languages fall back to English. Preview uses clearly labeled sample data and sends no quota requests.

简体中文

Token Orb 是适用于 macOS 14 及以上的桌面额度和余额看板。一次配置一个自定义厂商地址和一个 API Key。

正在准备全球 App Store 上架，一次性买断 USD 1.99，无订阅或应用内购买。目前尚未开放购买，当地价格以商店为准。购买应用不包含第三方额度或查询费用。

界面支持英文和简体中文，其他系统语言回退英文。预览使用明确标记的演示数据，不发起额度查询。
