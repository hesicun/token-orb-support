Token Orb 使用帮助

开始使用

  1. 首次打开进入预览模式，可先拖动水晶球并调节预览百分比。
  2. 右键球身，选择“用量与设置”。
  3. 关闭预览模式，选择 MiniMax 中国站或国际站。
  4. 输入你已有的 Token Plan 订阅 Key，点击“保存并刷新”。

日常操作

单击球身切换 5 小时与本周剩余额度；按住拖动到桌面任意位置；右键打开设置。菜单栏的水滴图标可以显示或隐藏水晶球、立即刷新及退出。

球壁浅白圆环表示当前额度周期已过去的比例，完成一圈表示到达该周期结束时间。没有可靠重置时间时不会伪造进度。显示以 MiniMax 返回的数据为准，周期结束后的额度需要等待下一次查询。

无法查询或数据没有更新

确认账户区域与 Key 匹配、Token Plan 仍有效、网络可以访问对应 MiniMax 服务。普通按量 API Key 不一定适用于 Token Plan。出现连接错误时可能保留上次成功结果，请结合“上次更新”和错误提示判断。不要将旧结果当成实时额度。

隐私与费用

App 免费，不包含 MiniMax 套餐。应用只查询额度，不发送生成请求。Key 保存在本机钥匙串；可在设置中删除。请阅读隐私政策。
