让每一份额度，都看得见。

Token Orb 把 MiniMax Token Plan 的剩余额度变成桌面上的绿色水晶球。轻点切换 5 小时与每周额度，拖动感受液体晃动，沿球壁的浅白圆环查看当前周期已过去的进度。

适用于 macOS 14 及以上，支持 Apple 芯片和 Intel Mac。App 免费；真实用量功能需要你已有的有效 MiniMax Token Plan 和订阅 Key，不包含套餐或 API 额度。

预览模式不需要账户。剩余额度较高时呈绿色，降低后渐变为黄色和深色。实际额度、周期与重置时间以 MiniMax 返回的数据为准。
